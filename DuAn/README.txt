GFA26SE110 - LaTeX project

Cau truc:
- main.tex: file chinh
- chapters/: cac chuong tach rieng
- images/: de trong, dung de dat hinh UML sau nay

Cach chay tren Windows:
1. Cai MiKTeX (khuyen nghi) hoac TeX Live.
2. Mo main.tex bang TeXworks/TeXstudio.
3. Chon pdfLaTeX.
4. Compile main.tex.

Luu y:
- Khong can viet code he thong theo yeu cau hien tai; day la bo khung tai lieu LaTeX.
- Cac ten thanh vien trong main.tex can thay bang ten that.
- Cac so lieu ket qua kiem thu can cap nhat sau khi nhom thuc hien.
- Cac hinh UML co the them vao thu muc images va chen vao cac chuong tuong ung.
