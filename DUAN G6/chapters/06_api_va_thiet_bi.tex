\section{Nguyên tắc xác thực}
\begin{enumerate}
  \item User đăng nhập bằng credential hợp lệ.
  \item Password chỉ được lưu dưới dạng hash; tuyệt đối không lưu plaintext.
  \item API kiểm tra authentication trước các endpoint riêng tư.
  \item Authorization kiểm tra role trước các thao tác quản trị.
  \item Gateway/device cần có cơ chế credential riêng; chi tiết certificate/token cần được nhóm xác định khi triển khai.
\end{enumerate}

\section{Thiết kế offline queue}
Gateway nên lưu mỗi record cùng các metadata:
\begin{itemize}
  \item local identifier;
  \item sensor identifier;
  \item measurement payload;
  \item collection timestamp;
  \item synchronization status;
  \item retry count;
  \item last retry timestamp;
  \item error reason nếu có.
\end{itemize}

Khi server trả kết quả batch, gateway chỉ đánh dấu các record đã được server xác nhận. Record lỗi tạm thời được retry; record lỗi dữ liệu cần chuyển sang trạng thái cần xử lý thay vì retry vô hạn.

\section{Duplicate prevention}
Một chiến lược có thể dùng là tạo idempotency key từ định danh sensor + measurement timestamp + sequence/local ID. Backend kiểm tra khóa này trước khi insert. Cách cụ thể phải được thống nhất với firmware/gateway để tránh loại nhầm hai measurement hợp lệ có timestamp giống nhau.

\section{Telemetry và mission monitoring}
Mission monitoring có thể nhận battery, waypoint và status khi telemetry khả dụng. Hệ thống nên ghi timestamp cho từng event để phục vụ dashboard và báo cáo. Direct UAV flight control không thuộc scope; API chỉ quản lý mission/configuration và theo dõi trạng thái.
